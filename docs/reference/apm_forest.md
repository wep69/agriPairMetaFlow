# Draw a publication-quality forest plot

Draw a publication-quality forest plot. This conservative manual
snapshot is regenerated from the authoritative roxygen source before
release.

## Usage

``` r
apm_forest(model, data = NULL, slab = NULL, transform = c("auto", "none", "exp", "percent"), sort = NULL, subgroup = NULL, prediction = TRUE, columns = NULL, interactive = FALSE, theme = "agri")
```

## Value

A documented agriPairMetaFlow S3 object or presentation object,
depending on the function.
