# agriPairMetaFlow: treatment-control meta-analysis for agronomy

`agriPairMetaFlow` provides an estimand-first, design-first interface
for treatment-versus-control evidence synthesis. Version 0.4.0 adds
joint multivariate outcome synthesis and Bayesian workflows while
preserving the dependence-aware, dose-response, meta-regression,
prediction, and plotting layers introduced in earlier versions. Backend
objects remain available for auditability and local numerical
validation.
