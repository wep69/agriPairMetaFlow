# Synthetic biochar multiresponse teaching data

Eight deterministic synthetic agronomic studies reporting yield, soil
carbon, and N2O responses to biochar versus no biochar. These data are
for teaching and validation, not empirical evidence.

## Usage

``` r
biochar_multiresponse
```

## Format

A data frame with 24 rows and 18 variables, including study, outcome,
treatment-control summaries, lnRR, yi, vi, sei, and effect-measure
metadata.

## Source

Synthetic data generated and frozen by the package development workflow.
